# Cloud Infrastructure Monitor

A hands-on Cloud & DevOps engineering project covering infrastructure provisioning, configuration management, containerisation, and CI/CD pipeline setup using industry-standard tooling.

## Tech Stack

| Layer | Tools |
|-------|-------|
| Infrastructure as Code | Terraform |
| Configuration Management | Ansible |
| Containerisation | Docker |
| Orchestration | Kubernetes (Minikube / kubectl) |
| CI/CD | Jenkins |
| Cloud Provider | AWS (EC2, S3, VPC) |

## Project Structure

```
1_Cloud_Infrastructure_Monitor/
├── q5-cloud-native/          # Terraform + Ansible provisioning scripts
│   ├── terraform/            # AWS EC2/VPC infrastructure definitions
│   └── ansible/              # Server configuration playbooks
├── q7-terraform/             # Terraform state and variable configs
├── q8-s3-terraform/          # S3 bucket provisioning via Terraform
├── q9-ansible/               # Ansible playbook for app deployment
├── vle4/                     # Terraform practice environment
├── Cloud-DevOps-Lab/         # Docker labs and VLE experiments
├── DevOps_Experiments/       # Kubernetes pod YAML and VLE practicals
└── Essential_Cloud_DevOps_PBL/ # Jenkins CI/CD pipeline project
```

## Key Implementations

- **Terraform** modules to provision AWS EC2 instances, VPCs, and S3 buckets
- **Ansible** playbooks for automated server setup and application deployment
- **Docker** containerisation labs (images, volumes, networking)
- **Kubernetes** pod and deployment manifests
- **Jenkins** CI/CD pipeline configuration
